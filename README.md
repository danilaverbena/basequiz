## Architecture

- **Anti-cheat:** off-chain backend signs `AnswerVerdict` (EIP-712) using a `trustedSigner` key registered in the contract. Server is the single source of truth on correctness; on-chain `submitAnswer()` only accepts the signed verdict.
- **Progression:** every 5 correct in a row → level up (cap 20). Wrong answer resets streak + locks that question on-chain for 24 h.
- **Attestations:** each level-up automatically writes an EAS attestation to the registered schema (`uint8 level, uint32 totalCorrect, uint64 timestamp, uint16 quizVersion`).

## Quick start

### Contracts (Foundry)

```bash
cd contracts
forge install foundry-rs/forge-std OpenZeppelin/openzeppelin-contracts
forge test                                                # 19 unit
forge test --fork-url https://mainnet.base.org            # 22 incl. real-EAS fork
```

### Web (Next.js)

```bash
cd web
npm install
cp .env.example .env   # fill SIGNER_PRIVATE_KEY (must equal contract.trustedSigner)
npm run dev            # http://localhost:3000
```

### Deploy

```bash
# 1. Register the EAS schema (one time, returns UID)
forge script script/RegisterSchema.s.sol --rpc-url base --broadcast

# 2. Deploy the contract
forge script script/Deploy.s.sol --rpc-url base --broadcast --verify

# 3. Push to Vercel and set env vars (see web/README.md)
```
